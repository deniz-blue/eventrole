# Evnt Bot

Discord bot designed for a Specific Purpose™️

## Instructions

Skip to section:
- [Event Organizers](#event-organizers)
- [Server Administrators](#server-administrators)

### Event Organizers

- React to any message with 📌 or 📍 inside the event forum post to pin it.
- React with 🗑️ to remove a pin.

### Server Administrators

- Use the `/settings` command to configure the bot for your server.
  - You can set which Forum Channels it should use for events.
  - You can also set a role to get mentioned when an event is created on a per-channel basis.
- Use `/track` on an existing forum post to create a role for it
